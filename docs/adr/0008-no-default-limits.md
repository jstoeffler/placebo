# No turn, cost or time limit by default

Caps stop the tool from working more often than they save money: a run that is cut short is a failed run that pollutes the pass rate and the verdict. All three limits exist as opt-in suite settings, and the SDK supports them natively. Retries apply only to infrastructure errors such as a failed spawn or a rate-limit response, never to the agent's own behavior.
