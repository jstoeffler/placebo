# Per-metric verdicts with an equivalence margin; never an overall winner

Each metric row gets exactly one of helps, harms, placebo or no evidence, where placebo requires the whole range to sit inside a declared margin. There is no composite score and no declared winner; the card leads with pass rate and cost by convention, and trade-offs are left to the reader.

## Considered options

A weighted composite score, rejected because it hides trade-offs. A required user-declared primary metric, rejected as friction on the first run. Three verdicts without placebo, rejected because "no evidence" would be read as "does nothing", which the data cannot support.
